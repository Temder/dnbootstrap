# Info

All credit goes to the original creator of this project (https://github.com/VSMobile/dnbootstrap). I added to this with AI so I could create a better controlling system for my liking.

**What is added**
- joystick, configurable background color and icon
- mod importing by selecting "open with" on a zip file in a file manager (e.g. FX File Explorer) and select the app dnbootstrap (not all mods work)
- minecraft mobile like touch controls (short touch → right mouse click, long touch holding → left mouse holding)

**Installation instruction**

Note: You need to buy the game and have an game account to play it on Android. All steps can be done on your phone.
1. Download APK file [app-debug.apk](https://github.com/Temder/dnbootstrap/releases/download/debug/app-debug.apk)
2. Open the downloaded file and install the app (it will ask to enable installing from unknown sources if needed)
3. Download a Vintage Story "Linux tar.gz Archive (full)" below version 1.22 (tested version 1.21.6 download link: [https://cdn.vintagestory.at/gamefiles/stable/vs_client_linux-x64_1.21.6.tar.gz](https://cdn.vintagestory.at/gamefiles/stable/vs_client_linux-x64_1.21.6.tar.gz))
4. Open dnbootstrap app and click on button
5. select downloaded "Linux tar.gz Archive (full)" file and wait for extraction
6. login with your game account
7. (optional) install mods by selecting "open with" on a zip file in a file manager (e.g. FX File Explorer) and select the app dnbootstrap (recommended mod: [StepUp (continued)](https://mods.vintagestory.at/download/25360/stepupcontinued_0.0.1.zip) see mod list below for working mods)
